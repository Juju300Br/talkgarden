Objetivos

Objetivo geral
Desenvolver um site educativo que apoie a alfabetização e a linguagem de crianças com TDL, com atividades lúdicas.
Objetivos específicos
  • 1Levantar os requisitos e modelar com a UML
  • 2Criar telas pensadas para crianças
  • 3Programar com HTML, CSS e JavaScript
  • 4Modelar o banco de dados
